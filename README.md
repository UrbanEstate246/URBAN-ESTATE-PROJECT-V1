# UrbanEstate

Verified real estate platform for Kenya.

## Stack
- Frontend: Next.js 14 + TypeScript + Tailwind
- Database: Supabase (PostgreSQL + Auth)
- API: Netlify Functions (Serverless)
- Images: Cloudinary
- CDN: Cloudflare
- Hosting: Netlify

## Local Development

```bash
cd frontend
npm install
cp .env.example .env.local
# Edit .env.local with credentials
npm run dev
```
